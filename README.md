## Теоретичні відомості

Двозв'язний список (`std::list`) — динамічна структура даних, у якій кожен вузол містить дані та два вказівники: на попередній (`prev`) і наступний (`next`) елементи. Це дозволяє рухатися списком в обидва боки та вставляти або видаляти елементи в довільному місці за час O(1) за наявності ітератора. Прямий доступ за індексом (`[]`, `at()`) не підтримується.

Для роботи потрібен заголовний файл `<list>`.

Використані методи та засоби:

| Метод / засіб | Призначення |
|---|---|
| `push_back(val)`, `push_front(val)` | додає елемент у кінець / на початок списку |
| `insert(it, val)` | вставляє елемент **перед** позицією `it` |
| `erase(it)` | видаляє елемент у позиції `it`, повертає ітератор на наступний |
| `remove_if(pred)` | видаляє всі елементи, що задовольняють умову |
| `sort(cmp)` | сортує список (метод контейнера) |
| `begin()`, `end()` | ітератори на початок і позицію після кінця |
| `std::next(it)` | копія ітератора, зміщена на 1 позицію вперед |

## Завдання 1

**Умова (варіант 1, тип `int`):** кількість елементів списку `N` та їх значення ввести з клавіатури. Видалити елемент безпосередньо після кожного 4, якщо він існує. Вставити 0 перед кожним 1.

**Хід роботи:**

1. Зчитуємо `N` (перевіряємо, що `N > 0`) і `N` цілих чисел, записуємо їх у `list<int>` через `push_back`.
2. Проходимо списком ітератором. Якщо `*it == 4`, обчислюємо `next(it)`. Якщо він не дорівнює `end()`, видаляємо цей елемент через `erase`.
3. Проходимо списком вдруге. Якщо `*it == 1`, викликаємо `insert(it, 0)`, адже `insert` вставляє елемент перед позицією ітератора.
4. Виводимо список на початку, після кожної операції та в кінці.

**Код програми** (`lab11_task1.cpp`):

```cpp
#include <iostream>
#include <list>
#include <iterator>
#ifdef _WIN32
#include <windows.h>
#endif
using namespace std;

void printList(const string& title, const list<int>& l) {
    cout << title;
    if (l.empty()) cout << "(список порожній)";
    for (int x : l) cout << x << " ";
    cout << endl;
}

int main() {
#ifdef _WIN32
    SetConsoleOutputCP(65001);
    SetConsoleCP(65001);
#endif

    int n;
    cout << "Введіть кількість елементів N (N > 0): ";
    while (!(cin >> n) || n <= 0) {
        cin.clear();
        cin.ignore(10000, '\n');
        cout << "Помилка! N має бути додатним цілим числом. Повторіть: ";
    }

    list<int> numbers;
    cout << "Введіть " << n << " цілих чисел: ";
    for (int i = 0; i < n; ++i) {
        int x;
        while (!(cin >> x)) {
            cin.clear();
            cin.ignore(10000, '\n');
            cout << "Помилка! Введіть ціле число: ";
        }
        numbers.push_back(x);
    }

    printList("\nПочатковий список:                   ", numbers);

    // 1) Видалення елемента після кожного 4
    int removed = 0;
    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        if (*it == 4) {
            auto nxt = next(it);
            if (nxt != numbers.end()) {
                numbers.erase(nxt);
                ++removed;
            }
        }
    }
    printList("Після видалення елементів після 4: ", numbers);
    cout << "  (видалено елементів: " << removed << ")\n";

    // 2) Вставка 0 перед кожним 1
    int inserted = 0;
    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        if (*it == 1) {
            numbers.insert(it, 0);
            ++inserted;
        }
    }
    printList("Після вставки 0 перед кожним 1:    ", numbers);
    cout << "  (вставлено нулів: " << inserted << ")\n";

    printList("\nРезультуючий список:                 ", numbers);
    return 0;
}
```

## Завдання 2

**Умова (варіант 1):** структура `Book` з полями *назва, автор, рік видання, ціна*. Створити `std::list` щонайменше з 5 записів. Виконати:

- вивід усіх записів у читабельному вигляді;
- додавання запису на початок і в кінець (`push_front` / `push_back`);
- фільтрацію: вивести книги після 2020 р.;
- видалення: видалити книги дешевші за 150 грн;
- сортування за ціною зростанням (метод `sort`).

**Хід роботи:**

1. Описуємо `struct Book { string title, author; int year; double price; }` і заповнюємо список 6 тестовими записами.
2. Виводимо таблицю. Після кожної операції виводимо результат.
3. `push_front` додає книгу «Чистий код», `push_back` — «Тореадори з Васюківки».
4. Для фільтрації проходимо списком і виводимо записи з `year > 2020`.
5. `remove_if` з умовою `price < 150` видаляє дешеві книги.
6. `sort` з порівнянням за полем `price` впорядковує список за зростанням ціни.

**Код програми** (`lab11_task2.cpp`):

```cpp
#include <iostream>
#include <list>
#include <string>
#include <iomanip>
#ifdef _WIN32
#include <windows.h>
#endif
using namespace std;

struct Book {
    string title;
    string author;
    int year;
    double price;
};

// кількість символів у UTF-8 рядку (для рівного вирівнювання кирилиці)
size_t utf8Len(const string& s) {
    size_t n = 0;
    for (unsigned char c : s)
        if ((c & 0xC0) != 0x80) ++n;
    return n;
}

string pad(const string& s, size_t w) {
    size_t l = utf8Len(s);
    return l >= w ? s : s + string(w - l, ' ');
}

void printBooks(const list<Book>& books) {
    cout << pad("Назва", 26) << pad("Автор", 24) << pad("Рік", 7) << "Ціна (грн)\n";
    cout << string(70, '-') << "\n";
    if (books.empty()) {
        cout << "(список порожній)\n";
        return;
    }
    for (const Book& b : books) {
        cout << pad(b.title, 26) << pad(b.author, 24)
             << pad(to_string(b.year), 7)
             << fixed << setprecision(2) << b.price << "\n";
    }
}

int main() {
#ifdef _WIN32
    SetConsoleOutputCP(65001);
    SetConsoleCP(65001);
#endif

    list<Book> books = {
        {"Кобзар",                "Тарас Шевченко",        2019, 280.00},
        {"Тіні забутих предків",  "Михайло Коцюбинський",  2021, 120.00},
        {"Лісова пісня",          "Леся Українка",         2022, 145.50},
        {"Захар Беркут",          "Іван Франко",           2018,  95.00},
        {"Місто",                 "Валерьян Підмогильний", 2023, 210.00},
        {"Перехресні стежки",     "Іван Франко",           2021, 175.00}
    };

    cout << "1) Початковий список книг:\n";
    printBooks(books);

    books.push_front({"Чистий код", "Роберт Мартін", 2022, 890.00});
    books.push_back({"Тореадори з Васюківки", "Всеволод Нестайко", 2024, 130.00});
    cout << "\n2) Після додавання книги на початок і в кінець:\n";
    printBooks(books);

    cout << "\n3) Книги, видані після 2020 р.:\n";
    list<Book> filtered;
    for (const Book& b : books)
        if (b.year > 2020) filtered.push_back(b);
    printBooks(filtered);

    books.remove_if([](const Book& b) { return b.price < 150; });
    cout << "\n4) Після видалення книг дешевших за 150 грн:\n";
    printBooks(books);

    books.sort([](const Book& a, const Book& b) { return a.price < b.price; });
    cout << "\n5) Після сортування за ціною (зростання):\n";
    printBooks(books);

    return 0;
}
```

## Висновок

У лабораторній роботі я ознайомилась з двозв'язним списком і контейнером `std::list` та набула практичних навичок роботи з ним за допомогою двонаправлених ітераторів.

У завданні 1 я опрацювала список цілих чисел. Видалила елемент після кожного 4 за допомогою `std::next` та `erase` і вставила 0 перед кожним 1 за допомогою `insert`. Під час видалення потрібно перевіряти, що наступний елемент існує. Під час вставки `insert` додає елемент перед позицією ітератора, тому вставка не порушує обхід списку.

У завданні 2 я створила список структур `Book` і виконала над ним типові операції: додавання на початок і в кінець (`push_front`, `push_back`), фільтрацію за роком видання, видалення за умовою (`remove_if`) та сортування за ціною методом `sort`. Контейнер `std::list` зручний для частих вставок і видалень у довільному місці, але не підтримує доступ за індексом. Тому для сортування використовують власний метод `list::sort`, а не `std::sort`.
